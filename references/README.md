# Reference reels

Style references for the editing guide ("The Butter Edit"). The videos themselves are not committed; download them again with:

```bash
cd references
yt-dlp -o "%(id)s.%(ext)s" --write-info-json \
  "https://www.instagram.com/reel/DbpmMqkAaob/" \
  "https://www.instagram.com/reel/DcXgYHpAj4P/" \
  "https://www.instagram.com/reel/DX_25tYAiKh/"
```
